# Mockups Visuais do MagicBoxV2

Este diretório contém mockups visuais das principais telas do MagicBoxV2 em ambos os temas (Dark Neon e Light Clean).

## Estrutura de Telas

1. **Tela Principal**
   - Visão geral das caixas cadastradas
   - Acesso rápido às principais funcionalidades
   - Barra de navegação inferior

2. **Tela de Etiquetas**
   - Seleção de modelos Pimaco integrada
   - Preview em tempo real com margens coloridas
   - Opções de exportação (PDF Vetorial, EPS)

3. **Tela de Reconhecimento de Objetos**
   - Interface de captura de imagem
   - Visualização dos resultados do reconhecimento
   - Armazenamento permanente das imagens

4. **Detalhes da Caixa**
   - Informações completas da caixa
   - Lista de itens contidos
   - Visualização das imagens associadas

5. **Configurações**
   - Alternância entre temas
   - Preferências de impressão
   - Opções de backup e sincronização

## Temas

### Tema Dark Neon
- Fundo escuro (#121212)
- Acentos em azul neon (#00B4FF)
- Elementos de destaque em roxo neon (#9D00FF)

### Tema Light Clean
- Fundo branco (#FFFFFF)
- Acentos em azul (#1976D2)
- Elementos secundários em cinza azulado (#607D8B)

## Observações

Estes mockups foram criados para representar visualmente o design proposto para o MagicBoxV2. A implementação final pode apresentar pequenas variações, mantendo a essência do design e as funcionalidades descritas.

Para visualizar o aplicativo em funcionamento, execute o projeto Flutter e acesse através da porta configurada (padrão: http://localhost:62081/).
